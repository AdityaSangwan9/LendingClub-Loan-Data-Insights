# LendingClub-Loan-Data-Insights
Project

Data Analyst Assessment - Loan Default Analysis (Finance Sector)

Business Problem

A lending company wants to understand which borrowers are more likely to default on loans, so lending decisions and interest rates can be improved.

Dataset

Lending Club Loan Data (Kaggle) Link: https://www.kaggle.com/datasets/wordsforthewise/lending-club

What I Did
Collected the raw loan dataset and loaded it into Google Sheets.
Cleaned the data - removed missing values, fixed data types, standardized categories, and created new fields like default status and income range.
Analyzed the cleaned data to find patterns in defaults by credit grade, loan purpose, loan term, and income.
Identified 5 key insights and 1 surprising finding.
Listed data limitations and what conclusions cannot be made.
Gave 3 recommendations for management.
Built a dashboard in Looker Studio to show the findings visually.
Created a short presentation summarizing everything for management.
